System Architecture

The DSE Agentic Scraper strictly separates reasoning from execution. The LLM is used for high-level decision making, while deterministic Node.js code handles extraction.

1. Layered Extraction Strategies

The system tries fastest methods first: JSON `__NEXT_DATA__` → HTML DOM Parsing → Playwright Headless Browser.

2. LLM Capabilities

  • Anomaly Classification: Detects if a 200% EPS jump is a warning or critical.
  • Failure Diagnosis: Reads DOM snapshots when extraction fails to plan a recovery route.

3. Self-Healing

If validation fails, the Recovery Agent pauses the workflow, consults the LLM with the error context, and retries with a new strategy up to 3 times.
